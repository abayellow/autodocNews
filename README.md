##  Особенности

- Поддержка **iPhone** и **iPad**
- Адаптация под **горизонтальное и вертикальное положение экрана**
- Асинхронная загрузка и обновление данных через **Combine**
- Реактивное связывание данных и интерфейса (**Publisher → ViewModel → UI**)
- Кеширование изображений и данных для офлайн-доступа
- Чистая архитектура на основе **MVVM**
- Использование **DiffableDataSource** и **Compositional Layout** для гибких коллекций
